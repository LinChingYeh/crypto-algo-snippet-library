氣泡排序演算法 (Bubble Sort)

原理簡介

氣泡排序是一種簡單且直觀的排序演算法。它的運作方式是重複地走訪過要排序的數列，每次比較相鄰的兩個元素。如果這兩個元素的順序錯誤（例如前一個大於後一個），就將它們交換位置。這個走訪的過程會持續重複，直到整個數列中沒有任何需要交換的元素為止。因為在排序的過程中，較大的元素會像水底的氣泡一樣，逐次「浮」到數列的頂端，因此得名氣泡排序。

複雜度與效能分析

  • 最佳時間複雜度：O(n) (當數列已經是排序狀態時)
  • 平均時間複雜度：O(n^2) (一般隨機排列的情況)
  • 最壞時間複雜度：O(n^2) (當數列為完全反序時)
  • 空間複雜度：O(1) (為 In-place 排序，只需額外常數空間)

核心程式碼

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 氣泡排序函式
void bubbleSort(vector<int>& arr) {
    int n = arr.size();

    // 控制排序輪數
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;

        // 比較相鄰的兩個元素
        for (int j = 0; j < n - i - 1; j++) {
            // 如果左邊的數字大於右邊，就交換位置
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }

        // 如果這一輪沒有發生交換，代表排序已完成
        if (swapped == false) {
            break;
        }
    }
}

int main() {
    int n;

    cout << "Enter the number of elements: ";
    cin >> n;

    vector<int> arr(n);

    cout << "Enter " << n << " integers: ";
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }

    // 執行氣泡排序
    bubbleSort(arr);

    // 輸出排序結果
    cout << "Sorted result: ";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    cout << endl;

    return 0;
}
