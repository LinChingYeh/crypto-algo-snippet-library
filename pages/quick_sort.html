快速排序演算法 (Quick Sort)

原理簡介

快速排序是一種基於「分治法 (Divide and Conquer)」的高效排序演算法。它的運作原理是從數列中挑選一個元素作為「基準值 (Pivot)」（本實作選用最後一個元素）。接著進行「分割 (Partition)」操作，將所有小於等於基準值的元素移到基準值左邊，大於基準值的元素移到右邊。分割完成後，基準值就會落在其最終排序正確的位置。最後，演算法透過遞迴的方式，分別對基準值左側與右側的子數列重複上述步驟，直到整個數列排序完成。

複雜度與效能分析

  • 最佳時間複雜度：O(n log n) (當每次分割都能將數列完美對半切分時)
  • 平均時間複雜度：O(n log n) (在一般隨機排列的情況下，效能極佳，實務上常快於其他 O(n log n) 演算法)
  • 最壞時間複雜度：O(n^2) (當數列已經是排序或完全反序狀態，且每次基準值都選到最大或最小值，導致分割極度不平衡時)
  • 空間複雜度：O(log n) (雖然是 In-place 排序，但平均情況下需要 O(log n) 的遞迴呼叫堆疊空間；最壞情況會退化至 O(n))

核心程式碼

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 分割函式（Partition）
int partition(vector<int>& arr, int low, int high) {

    // 選擇最後一個元素作為基準值
    int pivot = arr[high];

    // 記錄小於或等於基準值的區域邊界
    int i = low - 1;

    // 將小於或等於基準值的元素移至左側
    for (int j = low; j < high; j++) {

        if (arr[j] <= pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }

    // 將基準值放到正確的位置
    swap(arr[i + 1], arr[high]);

    // 回傳基準值的索引
    return i + 1;
}

// 快速排序函式
void quickSort(vector<int>& arr, int low, int high) {

    // 當區域內至少有兩個元素時才進行排序
    if (low < high) {

        // 找到基準值的正確位置
        int pivotIndex = partition(arr, low, high);

        // 排序基準值左側的資料
        quickSort(arr, low, pivotIndex - 1);

        // 排序基準值右側的資料
        quickSort(arr, pivotIndex + 1, high);
    }
}

int main() {
    int n;

    cout << "Enter the number of elements: ";
    cin >> n;

    // 檢查輸入數量
    if (n <= 0) {
        cout << "Number of elements must be greater than 0!" << endl;
        return 0;
    }

    vector<int> arr(n);

    cout << "Enter " << n << " integers: ";
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }

    // 執行快速排序
    quickSort(arr, 0, n - 1);

    // 輸出排序結果
    cout << "Sorted result: ";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    cout << endl;

    return 0;
}
