選擇排序演算法 (Selection Sort)

原理簡介

選擇排序是一種簡單直觀的排序演算法。它的運作原理是將數列分為「已排序」與「未排序」兩個區域。在每一次的走訪中，演算法會在未排序的區域內尋找最小（或最大）的元素，找到後將其與未排序區域的第一個元素進行交換。這使得已排序區域的長度逐漸增加，直到所有元素都排列完成。選擇排序的特點是交換次數少，但無論數列初始狀態為何，它都會執行相同次數的比較。

複雜度與效能分析

  • 最佳時間複雜度：O(n^2) (即使數列已經排序，仍需進行所有比較來確認最小值)
  • 平均時間複雜度：O(n^2) (一般隨機排列的情況)
  • 最壞時間複雜度：O(n^2) (當數列為完全反序時)
  • 空間複雜度：O(1) (為 In-place 排序，只需額外常數空間存放最小值的索引)

核心程式碼

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 選擇排序函式
void selectionSort(vector<int>& arr) {
    int n = arr.size();

    // 控制排序輪數
    for (int i = 0; i < n - 1; i++) {

        // 假設目前位置就是最小值的位置
        int minIndex = i;

        // 尋找尚未排序區域中的最小值
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }

        // 將最小值與目前位置的元素交換
        if (minIndex != i) {
            swap(arr[i], arr[minIndex]);
        }
    }
}

int main() {
    int n;

    cout << "Enter the number of elements: ";
    cin >> n;

    // 檢查輸入數量
    if (n <= 0) {
        cout << "Number of elements must be greater than 0!" << endl;
        return 0;
    }

    vector<int> arr(n);

    cout << "Enter " << n << " integers: ";
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }

    // 執行選擇排序
    selectionSort(arr);

    // 輸出排序結果
    cout << "Sorted result: ";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    cout << endl;

    return 0;
}
