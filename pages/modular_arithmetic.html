模運算 (Modular Arithmetic)

原理簡介

模運算（Modular Arithmetic）是密碼學中最核心的數學工具，其概念類似於時鐘上的運算。當數值超過模數 m 時，會「繞回」到從 0 開始的範圍內。在 C/C++ 中，直接使用 `%` 運算子對負數取餘數時，結果可能仍為負數，因此實務上會使用 `(a % m + m) % m` 的技巧來確保結果恆為正。模運算具備高度的分配律特性，允許我們在進行加法、減法與乘法時，先對個別運算元取模，再對運算結果取模，這在密碼學處理極大數值（如 RSA 演算法）時，能有效防止變數發生整數溢位 (Integer Overflow)。

複雜度與效能分析

  • 最佳時間複雜度：O(1) (僅涉及常數次數的基礎算術運算與取餘數操作)
  • 平均時間複雜度：O(1) (時間開銷不隨數字大小呈線性增長，由處理器指令集決定常數時間)
  • 最壞時間複雜度：O(1) (無論正數或負數輸入，運算步驟皆固定不變)
  • 空間複雜度：O(1) (只需常數空間來儲存 a、b、m 及結果變數，無額外記憶體開銷)

核心程式碼

#include <iostream>
using namespace std;

// 將結果轉換成正餘數
long long mod(long long a, long long m) {
    return (a % m + m) % m;
}

int main() {
    long long a, b, m;

    cout << "===== Modular Arithmetic =====" << endl;

    cout << "Enter integer a: ";
    cin >> a;

    cout << "Enter integer b: ";
    cin >> b;

    cout << "Enter modulus m: ";
    cin >> m;

    // 檢查模數
    if (m <= 0) {
        cout << "Error: Modulus must be greater than 0!" << endl;
        return 0;
    }

    // 加法同餘公式
    long long add = mod(mod(a, m) + mod(b, m), m);

    // 減法同餘公式
    long long sub = mod(mod(a, m) - mod(b, m), m);

    // 乘法同餘公式
    long long mul = mod(mod(a, m) * mod(b, m), m);

    // 輸出結果
    cout << "\n===== Calculation Results =====" << endl;

    cout << "Addition: " << a << " + " << b
         << " mod " << m << " = " << add << endl;

    cout << "Subtraction: " << a << " - " << b
         << " mod " << m << " = " << sub << endl;

    cout << "Multiplication: " << a << " * " << b
         << " mod " << m << " = " << mul << endl;

    return 0;
}
