擴展歐幾里得演算法 (Extended Euclidean Algorithm)

原理簡介

擴展歐幾里得演算法不僅能像標準歐幾里得演算法一樣求出兩個整數 a 和 m 的最大公因數 (GCD)，還能同時找到滿足「貝祖等式 (Bezout's identity)」的整數係數 s 和 t，使得 a * s + m * t = GCD(a, m)。在密碼學中，當這兩個數互質，即 GCD(a, m) = 1 時，係數 s (經過對 m 取模正規化後) 就是 a 在模 m 之下的「乘法反元素 (Multiplicative Inverse)」。這在 RSA 等公鑰密碼體系中，是產生私鑰或進行模逆運算時極為核心的數學工具。

複雜度與效能分析

  • 最佳時間複雜度：O(1) (當其中一個數為 0 或 m 為 a 的倍數時，可直接返回結果)
  • 平均時間複雜度：O(log(min(a, m))) (隨著數字在遞迴取模中迅速減小，步數呈對數級成長)
  • 最壞時間複雜度：O(log(min(a, m))) (當輸入的兩個數字為相鄰的費氏數列時，所需計算的步驟最多)
  • 空間複雜度：O(log(min(a, m))) (由於採用遞迴呼叫，會消耗對應遞迴深度的系統呼叫堆疊空間)

核心程式碼

#include <iostream>
using namespace std;

// 擴展歐幾里得演算法
long long extendedGCD(long long a, long long b,
                      long long &s, long long &t) {

    // 終止條件
    if (b == 0) {
        s = (a >= 0) ? 1 : -1;
        t = 0;
        return (a >= 0) ? a : -a;
    }

    long long s1, t1;

    // 遞迴呼叫
    long long gcd = extendedGCD(b, a % b, s1, t1);

    // 計算 s 和 t
    s = t1;
    t = s1 - (a / b) * t1;

    return gcd;
}

int main() {
    long long a, m;
    long long s, t;

    cout << "Enter integer a: ";
    cin >> a;

    cout << "Enter modulus m (m > 1): ";
    cin >> m;

    // 檢查模數是否有效
    if (m <= 1) {
        cout << "Error: modulus must be greater than 1!" << endl;
        return 0;
    }

    // 執行擴展歐幾里得演算法
    long long gcd = extendedGCD(a, m, s, t);

    // 輸出最大公因數
    cout << "\nGreatest Common Divisor GCD = " << gcd << endl;

    // 輸出 s 和 t
    cout << "s = " << s << endl;
    cout << "t = " << t << endl;

    // 輸出貝祖等式
    cout << "\nBezout's identity:" << endl;
    cout << a << " * (" << s << ") + "
         << m << " * (" << t << ") = "
         << gcd << endl;

    // 判斷是否存在乘法反元素
    if (gcd == 1) {

        // 將 s 正規化至 0 ~ m-1
        long long inverse = (s % m + m) % m;

        cout << "\nMultiplicative Inverse:" << endl;
        cout << a << " mod " << m
             << " inverse = "
             << inverse << endl;
    }
    else {
        cout << "\nMultiplicative inverse does not exist!" << endl;
        cout << "Because GCD(a, m) is not equal to 1." << endl;
    }

    return 0;
}
