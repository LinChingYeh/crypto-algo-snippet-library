雞尾酒排序演算法 (Cocktail Sort)

原理簡介

雞尾酒排序（又稱雙向氣泡排序）是氣泡排序的一種變形。一般的氣泡排序每次都是單向地從左到右比較並將最大值推向右端，這會導致數列尾端的較小數字需要經過非常多次的輪替才能慢慢「爬」回前端（稱為烏龜現象）。雞尾酒排序透過交替進行「由左至右」與「由右至左」的雙向比較，能在每一輪同時將最大值推向右端，並將最小值推向左端，藉此改善氣泡排序在特定極端情況下的效能。

複雜度與效能分析

  • 最佳時間複雜度：O(n) (當數列已經是排序狀態時，只需走訪一輪即可提早結束)
  • 平均時間複雜度：O(n^2) (一般隨機排列的情況)
  • 最壞時間複雜度：O(n^2) (當數列為完全反序時)
  • 空間複雜度：O(1) (為 In-place 排序，僅需常數等級的額外空間)

核心程式碼

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 雞尾酒排序函式
void cocktailSort(vector<int>& arr) {
    int n = arr.size();

    // 設定尚未排序的左右邊界
    int left = 0;
    int right = n - 1;

    // 控制是否發生交換
    bool swapped = true;

    while (swapped) {
        swapped = false;

        // 第一階段：由左向右比較
        for (int i = left; i < right; i++) {
            // 如果左邊的數字大於右邊，就交換位置
            if (arr[i] > arr[i + 1]) {
                swap(arr[i], arr[i + 1]);
                swapped = true;
            }
        }

        // 如果沒有發生交換，代表排序已完成
        if (swapped == false) {
            break;
        }

        // 右邊界往左縮小
        right--;

        swapped = false;

        // 第二階段：由右向左比較
        for (int i = right; i > left; i--) {
            // 如果右邊的數字小於左邊，就交換位置
            if (arr[i] < arr[i - 1]) {
                swap(arr[i], arr[i - 1]);
                swapped = true;
            }
        }

        // 左邊界往右縮小
        left++;
    }
}

int main() {
    int n;

    cout << "Enter the number of elements: ";
    cin >> n;

    vector<int> arr(n);

    cout << "Enter " << n << " integers: ";
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }

    // 執行雞尾酒排序
    cocktailSort(arr);

    // 輸出排序結果
    cout << "Sorted result: ";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    cout << endl;

    return 0;
}
