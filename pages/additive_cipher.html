加法密碼 (Additive Cipher)

原理簡介

加法密碼是一種古典的替換式密碼（最著名的特例為凱撒密碼）。它的運作原理是將明文中的每一個英文字母，依照字母表順序向後（或向前）位移固定的位數，這個位移量即為「密鑰 (Key)」。當字母位移超過 Z 時會重新從 A 開始，這在數學上可視為對 26 取模（Modulo 26）的加法運算。解密時，只需加上負的密鑰（等同於 26 減去密鑰）再次取模，即可還原出原本的明文。

複雜度與效能分析

  • 時間複雜度：O(N) (N 為輸入的字串長度。演算法必須走訪字串中的每一個字元進行模運算，處理時間與字串長度成正比)
  • 空間複雜度：O(1) (由於是直接對傳入的字串進行字元替換，屬於 In-place 修改，除了儲存密鑰等少數變數外，不需要隨著字串長度增加額外的記憶體開銷)

核心程式碼

#include <iostream>
#include <string>
#include <limits>
using namespace std;

// 加法式密碼函式
string additiveCipher(string text, int key, bool decrypt) {

    // 將密鑰限制在 0~25 之間
    key = ((key % 26) + 26) % 26;

    // 如果是解密，則使用反向位移
    if (decrypt) {
        key = (26 - key) % 26;
    }

    // 逐一處理字串中的字元
    for (int i = 0; i < text.length(); i++) {

        // 處理大寫英文字母
        if (text[i] >= 'A' && text[i] <= 'Z') {
            text[i] = 'A' + (text[i] - 'A' + key) % 26;
        }

        // 處理小寫英文字母
        else if (text[i] >= 'a' && text[i] <= 'z') {
            text[i] = 'a' + (text[i] - 'a' + key) % 26;
        }
    }

    return text;
}

int main() {
    int choice, key;
    string text;

    cout << "===== Additive Cipher =====" << endl;
    cout << "1. Encryption" << endl;
    cout << "2. Decryption" << endl;

    cout << "Choose an option: ";
    cin >> choice;

    cout << "Enter the key: ";
    cin >> key;

    // 清除輸入緩衝區
    cin.ignore(numeric_limits<streamsize>::max(), '\n');

    cout << "Enter text: ";
    getline(cin, text);

    // 執行加密或解密
    if (choice == 1) {
        cout << "Encrypted result: "
             << additiveCipher(text, key, false) << endl;
    }
    else if (choice == 2) {
        cout << "Decrypted result: "
             << additiveCipher(text, key, true) << endl;
    }
    else {
        cout << "Invalid option!" << endl;
    }

    return 0;
}
