插入排序演算法 (Insertion Sort)

原理簡介

插入排序的運作原理非常類似於我們打撲克牌時整理手牌的方式。演算法會將整個數列分為「已排序」和「未排序」兩個區域。一開始，會將數列的第一個元素視為已排序區域。接著，每次從未排序區域中取出第一個元素（作為 key），並在已排序的序列中由後往前掃描，將大於 key 的元素逐一往右移動，最後將 key 插入到正確的空位。這個過程會不斷重複，直到所有元素都插入完畢。

複雜度與效能分析

  • 最佳時間複雜度：O(n) (當數列已經是排序狀態時，內層迴圈每次只需比較一次便會直接中斷)
  • 平均時間複雜度：O(n^2) (一般隨機排列的情況)
  • 最壞時間複雜度：O(n^2) (當數列為完全反序時，每次插入都需要移動已排序區域的所有元素)
  • 空間複雜度：O(1) (為 In-place 排序，只需額外的常數空間儲存 key 等變數)

核心程式碼

#include <iostream>
#include <vector>
using namespace std;

// 插入排序函式
void insertionSort(vector<int>& arr) {
    int n = arr.size();

    // 從第二個元素開始排序
    for (int i = 1; i < n; i++) {

        // 儲存目前要插入的元素
        int key = arr[i];

        // 從已排序區域的最後一個元素開始比較
        int j = i - 1;

        // 將大於 key 的元素往右移動
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }

        // 將 key 插入正確的位置
        arr[j + 1] = key;
    }
}

int main() {
    int n;

    cout << "Enter the number of elements: ";
    cin >> n;

    // 檢查輸入數量
    if (n <= 0) {
        cout << "Number of elements must be greater than 0!" << endl;
        return 0;
    }

    vector<int> arr(n);

    cout << "Enter " << n << " integers: ";
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }

    // 執行插入排序
    insertionSort(arr);

    // 輸出排序結果
    cout << "Sorted result: ";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    cout << endl;

    return 0;
}
